GovtPath India — static website prototype

Pages:
/                 Home
/jobs             Government job listings with working search and filters
/exams            Competitive exam guides
/results          Results, admit cards, answer keys and exam calendar
/materials        Study materials and resource library
/mock-tests       Working browser-based timed practice test and local history
/current-affairs  Daily current affairs articles
/login            Student login form preview
/register         Registration form preview
/dashboard        Student dashboard preview
/admin            Admin console preview

The site uses Bootstrap 5 and Tailwind CDN references, plus shared theme.css and app.js.
The mock test and theme preference work locally in the browser. Authentication, backend,
file uploads, official PDFs, live notices, and persistent student/admin management are not
implemented in this static prototype. Production requirements would need Spring Boot,
Spring Security, Spring Data JPA and MySQL, as well as verified official content links.

Sample job and current-affairs entries are illustrative. Verify all dates and eligibility
against official recruiting bodies before taking action.
